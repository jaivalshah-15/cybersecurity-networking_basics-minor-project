# Cybersecurity & Networking Fundamentals

## About the Project

This repository contains my first minor project from the Unlox Cybersecurity Foundation Batch.

The project focuses on the fundamentals of cybersecurity, computer networking, IP addressing, subnetting, and network troubleshooting.

## Topics Covered

- Cybersecurity fundamentals and the CIA Triad
- Threats, vulnerabilities, risks, and attacks
- Network types and network devices
- Internet communication and DNS
- IPv4, IPv6, and IP classification
- Subnet masks, CIDR, and subnet calculations
- Network design and IP troubleshooting

## Objectives

- Understand the basic principles of cybersecurity.
- Learn how computers communicate over networks.
- Practice IP addressing and subnet calculations.
- Develop logical troubleshooting skills.
- Document technical concepts and learning progress using Git and GitHub.
