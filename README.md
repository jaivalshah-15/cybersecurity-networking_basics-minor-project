# Cybersecurity & Networking Fundamentals

## About the Project

This repository contains my first minor project from the Unlox Cybersecurity Foundation Batch.

The project focuses on cybersecurity fundamentals, computer networking, IP addressing, subnetting, network design, and basic network troubleshooting.

## Topics Covered

- Cybersecurity fundamentals and the CIA Triad
- Vulnerabilities, threats, risks, and cyberattacks
- Network security and other security domains
- Network types and networking devices
- Internet communication, DNS, and TCP/IP
- IPv4, IPv6, and IP address classification
- Subnet masks, CIDR notation, and subnet calculations
- Variable Length Subnet Masking (VLSM)
- Network design and troubleshooting
