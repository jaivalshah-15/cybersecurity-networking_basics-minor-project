# Section A — Cybersecurity Fundamentals

## Q1.Fundamentals (5 Marks)

### 1.What is Cybersecurity?

Cybersecurity is the practice to protect computers from any unauthorized      access,cyber attacks or theft of data.It ensures safety and also that necessary systems remain accessible to authorized users only.

### 2. Why Is Cybersecurity Important?

Cybersecurity is important because it:

- Protects sensitive and personal information from unauthorized access.
- Prevents unauthorized users from accessing computer systems and networks.
- Helps protect organizations against malware,phishing and other cyberattacks.
- Maintains user trust and supports the safe operation of digital services.

### 3. The CIA Triad

The CIA Triad is a fundamental information security model consisting of three principles: Confidentiality,Integrity and Availability.

**A. Confidentiality**

Confidentiality ensures that information is accessible only to authorized people or systems.

**Example:** My College uses passwords and access permissions to ensure that the students can view their own marks but cannot access other students' private records.

**B. Integrity**

Integrity ensures that information remains accurate,complete and protected against unauthorized modification.

**Example:** The College's marks database uses access controls and audit logs to help prevent unauthorized changes to students' examination results.

**C. Availability**

Availability ensures that authorized users can access information and services when they need them.

**Example:** College maintains backups, reliable servers, and recovery procedures so that its online student portal can be restored if a server fails.

### Conclusion

The CIA Triad provides a foundation for cybersecurity. Confidentiality protects information from unauthorized access, integrity protects its accuracy, and availability ensures that authorized users can access it when required.



## Q2. Security Thinking (5 Marks)

### 1. Vulnerability

A vulnerability is a weakness or flaw in a system,application,network or security configuration that could be exploited.

**Example:** A web application contains an unpatched software vulnerability that could allow unauthorized access.

### 2. Threat

A threat is a potential cause of harm that could exploit a vulnerability and affect a system or its information.

**Example:** A cybercriminal attempting to exploit an unpatched web application is a threat.

### 3. Risk

Risk is the possibility of loss or damage when a threat exploits a vulnerability. It depends on factors such as the likelihood of the event and the severity of its impact.

**Example:** If the vulnerable web application stores customer information, there is a risk of data exposure and financial loss.

### 4. Attack

An attack is an actual attempt to exploit a vulnerability or compromise the confidentiality,integrity or availability of a system.

**Example:** A cybercriminal sends a malicious request that exploits the web application's vulnerability to gain unauthorized access.

### Difference Between the Four Terms

| Term | Meaning | Example |
|---|---|---|
| Vulnerability | A weakness that could be exploited | Unpatched web application |
| Threat | A potential cause of harm | Cybercriminal attempting exploitation |
| Risk | The possibility and impact of harm | Possible exposure of customer data |
| Attack | An attempt to compromise a system | Malicious request exploiting the weakness |

### Conclusion

A vulnerability is a weakness, a threat is a potential source of harm, risk describes the possibility and impact of harm, and an attack is an attempt to compromise a system. Understanding these differences helps organizations identify security problems and choose appropriate protective measures.



## Q3. Types of Security (5 Marks)

### 1. Network Security

Network security protects computer networks and the data transmitted through them from unauthorized access, misuse, and cyberattacks.It uses measures such as firewalls,network monitoring and access controls.

**Example:** A company uses a firewall to block unauthorized network connections.

### 2. Application Security

Application security focuses on protecting software and web applications from vulnerabilities throughout their development and use.It includes secure coding,security testing and timely software updates.

**Example:** A developer validates user input to help prevent SQL injection attacks in a web application.

### 3. Cloud Security

Cloud security protects data,applications and infrastructure hosted on cloud platforms. It includes identity and access management, secure configuration, encryption, and monitoring.

**Example:** A company restricts access to its cloud storage so that only authorized employees can view confidential files.

### 4. Endpoint Security

Endpoint security protects devices connected to a network such as laptops,desktops and mobile phones.Common measures include antivirus software,endpoint detection tools and security updates.

**Example:** A university installs endpoint protection software on its computers to detect and block malware.

### 5. Information Security

Information security protects information against unauthorized access,disclosure,alteration,destruction or loss regardless of whether it is stored digitally,on paper or in another form.It supports the principles of confidentiality,integrity and availability.

**Example:** A hospital uses access permissions and encryption to protect patients' confidential records.

### Conclusion

Network, application, cloud, endpoint, and information security address different security needs. Together, they help organizations protect their systems, devices, applications, and sensitive information.
